# SalonCloud 使い方ガイド

最終確認日: 2026年6月9日

SalonCloudは、店舗内で写真・動画を撮影し、投稿として共有・管理するためのアプリです。

## 1. 最短で使い始める

1. アプリを開き、「はじめる」をタップします。
2. 表示名、メールアドレス、パスワードを入力してアカウントを作成します。
3. 「認証メールを確認してください」と表示されたら、届いたメール内の認証リンクをタップします。
4. アプリへ戻り、登録したメールアドレスでログインします。
5. 「店舗を作成する」または「店舗に参加する」を選びます。
6. 画面下中央のカメラから写真・動画を撮影します。
7. 撮影後に「投稿作成」を選び、内容を確認して「投稿する」をタップします。
8. 投稿は「ホーム」のタイムラインで店舗メンバーに共有されます。

## 2. 利用者の役割

| 役割     | 主な機能                                                                       |
| -------- | ------------------------------------------------------------------------------ |
| スタッフ | 撮影、投稿、タイムライン閲覧、自分の投稿の編集・削除、プロフィール編集         |
| 管理者   | スタッフ機能に加え、店舗番号の共有、投稿検索・承認・却下・保存、スタッフの削除 |
| オーナー | すべての管理機能、メンバーの役割変更、オーナー・管理者を含むメンバー管理       |

注意事項:

- 管理者が店舗から削除できるのはスタッフのみです。
- 役割を変更できるのはオーナーのみです。
- 店舗には最低1名のオーナーが必要です。
- 自分自身の役割変更や店舗からの削除はできません。

## 3. アカウント登録・ログイン

### 新規登録

1. 最初の画面で「はじめる」をタップします。
2. 表示名、メールアドレス、パスワード、確認用パスワードを入力します。
3. 利用条件を確認し、「アカウント作成」をタップします。
4. 認証メールが送信された場合は、メール内の認証リンクをタップします。
5. 「認証後にログイン」からログイン画面へ進みます。

パスワードには次の条件があります。

- 6文字以上
- 数字を1文字以上含む

認証メールが届かない場合は、迷惑メールフォルダを確認するか、「認証メールを再送」をタップしてください。

### ログイン

1. 最初の画面で「ログインはこちら」をタップします。
2. メールアドレスとパスワードを入力します。
3. 必要に応じて「ログイン状態を保持する」をオンにします。
4. 「ログイン」をタップします。

### パスワードを忘れた場合

1. ログイン画面の「パスワードをお忘れの方」をタップします。
2. 登録済みのメールアドレスを入力します。
3. 「リセットメールを送信」をタップします。
4. 届いたメール内のリンクを開き、新しいパスワードを設定します。

## 4. 店舗を設定する

アカウント登録後は、店舗の作成または既存店舗への参加が必要です。

### 店舗を作成する

1. 「店舗を作成する」をタップします。
2. 店舗名を入力します。
3. 「作成する」をタップします。
4. 作成完了画面に表示される招待コードを保管します。
5. 「通常画面へ」をタップします。

店舗を作成したユーザーはオーナーになります。

### 店舗に参加する

1. オーナーまたは管理者から招待コードを受け取ります。
2. 「店舗に参加する」をタップします。
3. 招待コードを入力します。
4. 「参加する」をタップします。

アプリ内の「店舗番号」と「招待コード」は、どちらも店舗参加に使用する同じコードを指します。

### 店舗番号を共有する

オーナーまたは管理者だけが店舗番号を確認・共有できます。

1. ホームまたはプロフィール左上のメニューボタンをタップします。
2. メニュー上部のユーザー情報をタップします。
3. 「店舗情報」で店舗番号を確認します。
4. コピーボタンをタップし、参加するスタッフへ共有します。

## 5. メイン画面

画面下部には3つのタブがあります。

| タブ         | 内容                                     |
| ------------ | ---------------------------------------- |
| ホーム       | 店舗メンバーの投稿を表示するタイムライン |
| カメラ       | 写真・動画の撮影                         |
| プロフィール | 自分のプロフィールと投稿一覧             |

ホームまたはプロフィールの左上にあるメニューボタンから、ギャラリー、自分の投稿、新規投稿、各種設定を開けます。

## 6. 写真・動画を撮影する

初回利用時は、カメラやマイクへのアクセスを許可してください。

### 写真を撮影する

1. 画面下中央の「カメラ」をタップします。
2. 画面下部で「写真」を選択します。
3. 中央のカメラボタンをタップして撮影します。
4. 続けて撮影するか、投稿作成へ進みます。

### 動画を撮影する

1. カメラ画面下部で「動画」を選択します。
2. 必要に応じて「HD」または「4K」を選択します。
3. 中央のカメラボタンをタップして録画を開始します。
4. もう一度タップして録画を終了します。

動画撮影にはマイク権限も必要です。

### カメラ画面の操作

| 操作                       | 内容                             |
| -------------------------- | -------------------------------- |
| アルバムアイコン           | 端末内の写真・動画を選択         |
| グリッドアイコン           | 構図用のグリッドを表示・非表示   |
| フラッシュアイコン         | オフ、オン、自動を切り替え       |
| カメラ反転アイコン         | 背面カメラと前面カメラを切り替え |
| 画面をピンチ               | ズーム倍率を変更                 |
| 中央のカメラボタンを長押し | 明るさ（EV）調整を表示           |

撮影後に追加できるメディアは、写真・動画を合わせて最大5件です。

## 7. 投稿を作成する

投稿画面は、撮影後、ギャラリー、またはメニューの「新規投稿」から開けます。

1. 投稿する写真・動画を確認します。
2. 必要に応じて「写真を撮影」または「アルバム」から追加します。
3. タイトルを入力します。タイトルは任意で、最大100文字です。
4. 投稿メモを入力します。投稿メモは任意です。
5. カテゴリを選択します。
6. 右上の「投稿する」をタップします。

標準カテゴリ:

- カット
- カラー
- パーマ
- 縮毛
- トリートメント

「カテゴリを追加」から独自カテゴリを追加できます。追加したカテゴリを長押しすると削除できます。標準カテゴリは削除できません。

投稿には少なくとも1件の写真または動画が必要です。1投稿につき最大5件まで登録できます。

## 8. タイムラインを使う

「ホーム」では、同じ店舗に所属するメンバーの投稿を新しい順に確認できます。

- 画面を下へ引っ張ると最新状態に更新できます。
- 複数メディアがある投稿は、左右に切り替えて確認できます。
- 自分の投稿のメニューから「編集」または「削除」を選択できます。
- オーナーまたは管理者は、投稿の写真・動画を端末へ保存できます。

投稿の削除は取り消せません。

## 9. ギャラリーを使う

1. 左上のメニューボタンをタップします。
2. 「ギャラリー」を選択します。
3. 初回は写真・動画へのアクセスを許可します。
4. メディアをタップして選択します。
5. 「投稿作成」をタップします。

ギャラリーでは次の操作もできます。

- 端末のライブラリからメディアを追加
- 複数の写真・動画を選択
- 選択したメディアを削除
- 作成中の投稿へメディアを追加

投稿作成時に選択できるメディアは最大5件です。

## 10. 投稿を編集・削除する

### タイムラインから

1. 自分の投稿にあるメニューボタンをタップします。
2. 「編集」または「削除」を選びます。

### プロフィールから

1. 「プロフィール」を開きます。
2. 投稿画像をタップすると、自分の投稿を詳しく確認できます。
3. 投稿のメニューから編集・削除できます。

編集画面では、メディア、タイトル、投稿メモ、カテゴリを変更できます。メディアをすべて削除した状態では更新できません。

## 11. プロフィールを編集する

1. 画面下部の「プロフィール」をタップします。
2. 「プロフィールを編集」をタップします。
3. プロフィール画像または表示名を変更します。
4. 「保存」をタップします。

プロフィール画面では、所属店舗、役割、投稿数、採用数、自分の投稿一覧を確認できます。

## 12. メニューと設定

ホームまたはプロフィール左上のメニューボタンから、次の機能を利用できます。

- ギャラリー
- 自分の投稿
- 新規投稿
- プロフィール編集
- パスワード変更
- ダークモード
- ログアウト

「ヘルプ・使い方」と「お問い合わせ」は、現在アプリ内機能を準備中です。

## 13. 管理者・オーナー向け機能

管理機能は、左上のメニュー内に表示されます。

### 投稿を検索・確認する

「フィルタ検索」では、次の条件で店舗内の投稿を検索できます。

- タイトル・本文
- 投稿したスタッフ
- 役割
- 期間: 今日、今週、今月、3ヶ月、すべて
- カテゴリ
- メディア種別: 写真のみ、動画のみ、すべて
- 承認ステータス: 承認待ち、承認済み、却下
- 並び順: 新しい順、古い順

検索結果から投稿を開き、承認ステータスを変更したり、メディアを端末へ保存したりできます。複数投稿を選択すると、一括承認、一括却下、一括保存ができます。

### スタッフを管理する

「スタッフ一覧管理」では、店舗メンバーと投稿数を確認できます。

- オーナー: メンバーの役割変更と削除が可能
- 管理者: スタッフの削除が可能
- スタッフ: 管理画面は利用不可

メンバーを店舗から削除すると、そのユーザーは店舗の投稿閲覧と投稿作成ができなくなります。

## 14. 必要な端末権限

| 権限           | 使用目的                         |
| -------------- | -------------------------------- |
| カメラ         | 写真・動画の撮影                 |
| マイク         | 動画の音声録音                   |
| 写真・メディア | アルバムからの選択、端末への保存 |

誤って権限を拒否した場合は、端末の「設定」からSalonCloudの権限を開き、必要な項目を許可してください。

## 15. 困ったとき

### ログインできない

- メールアドレスとパスワードを確認してください。
- 新規登録直後は、届いたメールからメール認証を完了してください。
- パスワードを忘れた場合は、ログイン画面からリセットメールを送信してください。

### 店舗に参加できない

- 招待コードをもう一度確認してください。
- 前後に空白が入っていないか確認してください。
- オーナーまたは管理者に最新の店舗番号を確認してください。

### 撮影できない

- カメラ権限を許可してください。
- 動画の場合はマイク権限も許可してください。
- 他のアプリがカメラを使用している場合は、そのアプリを閉じてください。

### 写真・動画を保存できない

- 写真・メディアへのアクセス権限を許可してください。
- 端末の空き容量を確認してください。

### 投稿できない

- 写真または動画が1件以上追加されているか確認してください。
- 1投稿のメディア数が5件以内か確認してください。
- 店舗に参加済みか確認してください。
- 通信状態を確認して、もう一度お試しください。
